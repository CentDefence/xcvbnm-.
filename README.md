# RA1ZEN x MANNA GFX SHOP

Одностраничный сайт для позинг-шопа — чёрно-белая тема, экран загрузки с лого, плавающий фон с абстрактными 3D/currency-иконками, цены, FAQ (аккордеон), шаги заказа и контакты.

## 📁 Структура

```
.
├── index.html
├── logo-white.png
├── favicon.png
├── vazio.mp3        ← UdieNnx - VAZIO
├── disco.mp3         ← Surf Curse - Disco
├── work1.jpg … work11.jpg   ← примеры работ для плавающей карусели
├── .nojekyll
└── README.md
```

Все файлы лежат **плоско в корне репозитория**, без вложенных папок — так надёжнее при ручной загрузке через сайт GitHub (Add file → Upload files), подпапки иногда "теряются" при drag-n-drop.

## 🖼️ Портфолио (плавающая карусель)

Секция "Наши работы" — бесконечная горизонтально скроллящая лента карточек с примерами рендеров, слегка покачивающихся (как в референсе с tackyleague.com). Останавливается при наведении курсора.

Чтобы добавить/заменить работы: закинь картинку в корень репозитория (рядом с `index.html`), впиши имя файла в массив `WORKS` в конце `index.html`:
```js
const WORKS = [
  'work1.jpg', 'work2.jpg', ...
  'новая_работа.jpg',
];
```

## 🎯 Блок "Почему мы"

Секция с 6 цветными карточками (Качество, Красота, Рендеринг, Популярность, Скорость, Индивидуальность) — блок `.features-grid` в `index.html`, между ценами и шагами заказа. Каждая карточка — `.feature-card` с классом цвета (`fc-blue`, `fc-red`, `fc-purple`, `fc-orange`, `fc-cyan`, `fc-gold`).

## 🎵 Плеер

Внизу сайта плавающий стеклянный плеер (в стиле нижних панелей Telegram mobile / Spotify) — play/pause, следующий/предыдущий трек, прогресс-бар (кликабельный), и разворачиваемый плейлист (клик по самому плееру). Чтобы добавить свои треки — закинь mp3 в корень репозитория и допиши в массив `PLAYLIST` в конце `index.html`:

```js
const PLAYLIST = [
  { title:"VAZIO", artist:"UdieNnx", src:"vazio.mp3" },
  { title:"Disco", artist:"Surf Curse", src:"disco.mp3" },
  { title:"Название", artist:"Исполнитель", src:"файл.mp3" },
];
```

## 🚀 Деплой на GitHub Pages

1. Создай репозиторий → залей все файлы из этой папки
2. **Settings → Pages → Source:** branch `main`, папка `/ (root)` → Save
3. Через минуту сайт будет доступен на `https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПО/`

## ✏️ Что можно менять

- **Цены** — блок `.pricing-grid` в `index.html`, ищи `<div class="price-tag">`
- **FAQ** — блок `.faq-list`, каждый вопрос это `.faq-item` с `.faq-q` (вопрос) и `.faq-a-inner` (ответ)
- **Шаги заказа** — блок `.order-steps`
- **Контакты / ссылки** — блок `.contact-grid`, там же кнопки в hero (`.hero-buttons`)
- **Анкета** — блок `.anketa-box` внутри шага 2
